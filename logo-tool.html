YouTube Cover Logo Tool

Select your cover images. This tool will add the logo in the fixed position and save new PNG files.

Please select images first.
  1. Use Chrome or Edge on Windows and Mac.
  2. The default logo is built in.
  3. For a custom logo, use a transparent 1280x720 overlay image.
  4. New files will end with _with_logo.
  5. If folder saving is not supported, finished images will download as one ZIP file.
