YouTube Cover Logo Tool / YouTube封面贴Logo工具

Recommended steps / 推荐用法：
1. Unzip YT-logo-tool.zip. / 解压 YT-logo-tool.zip。
2. Open logo-tool.html. / 打开 logo-tool.html。
3. Choose a language: English, Bahasa Indonesia, or Simplified Chinese. / 选择语言：英语、印尼语或简体中文。
4. Select one or more cover images. / 选择一张或多张封面图片。
5. Optional: upload new logo files. Logos already included in assets are shown as options. / 可选：上传新的 logo 文件；assets 里已有的 logo 会显示为可选项。
6. Click “Start”. Finished images will download as one ZIP file. / 点击“开始”，完成图片会自动打包成一个 ZIP 下载。

Notes / 注意：
- Use Chrome or Edge on Windows and Mac. / Windows 和 Mac 都建议用 Chrome 或 Edge。
- The web tool already includes logo options from assets. You can also upload new logos in the page. / 网页工具已经内置 assets 里的 logo 选项，也可以在页面里上传新 logo。
- For a custom logo, use a transparent 1280x720 overlay image to keep the position correct. / 如果更换 logo，建议使用透明 1280x720 位置图，这样位置不会变。
- New files will end with _with_logo. Original files will not be changed. / 新文件名会加上 _with_logo，原图不会被覆盖。
- All finished images will download as one ZIP file. / 所有完成图片会打包成一个 ZIP 下载。

Mac backup option / Mac 备用用法：
You can also double-click mac-one-click.command and follow the prompts. / 也可以双击 mac-one-click.command，按提示选择原始封面文件夹和输出文件夹。
